# Icon sources

Python, Claude, and Upwork paths (Simple Icons v16): [Simple Icons](https://github.com/simple-icons/simple-icons), distributed under CC0. Brand names and marks belong to their respective owners.

AWS wordmark: [Simple Icons v13](https://cdn.jsdelivr.net/npm/simple-icons@13.0.0/icons/amazonwebservices.svg), CC0. Langfuse mark: [official repository](https://github.com/langfuse/langfuse/blob/main/web/public/icon.svg); see its upstream license.

LinkedIn: standard LinkedIn “in” mark. CV: locally authored document pictogram. Badge containers are locally authored; all assets are self-contained SVGs.

The standalone logo assets in `../icons/` reuse these same paths at 40px. The animated introduction in `../intro.svg` is locally authored using system fonts, with no copied reference artwork or embedded fonts.

Git, Docker, OpenCV, scikit-learn, and Model Context Protocol (MCP) logo paths: [Simple Icons v16](https://github.com/simple-icons/simple-icons/tree/16.0.0/icons), CC0. Local filenames use `scikit-learn.svg`; upstream uses `scikitlearn.svg`. MCP uses upstream `modelcontextprotocol.svg`, with dark/light fills for legibility.

Strands Agents mark: [official adaptive logo](https://github.com/strands-agents/docs/blob/main/site/src/assets/logo-auto.svg). See the [upstream license](https://github.com/strands-agents/docs/blob/main/LICENSE). Geometry and green strand are preserved; the gray strand is lightened on dark backgrounds for legibility.

The compact badges for Strands Agents, Git, Docker, OpenCV, scikit-learn, and MCP use the upstream logo paths documented above. Badge containers and labels are locally authored; MCP uses a light fill on the dark badge background.

OpenAI Agents SDK badge: OpenAI brand mark from [Simple Icons v13](https://cdn.jsdelivr.net/npm/simple-icons@13.0.0/icons/openai.svg), CC0, with the SDK name as its label. A2A badge: [official A2A white icon](https://github.com/a2aproject/A2A/blob/main/docs/assets/a2a_logo/icon/white/SVG/a2a_icon_white.svg); see the [upstream license](https://github.com/a2aproject/A2A/blob/main/LICENSE). Both use the existing locally authored compact container.
